## 1. PHP Introduction

PHP is a server-side scripting language used to create dynamic web applications.

### Main Concepts Covered

- PHP is a server-side scripting language.
- PHP can be embedded into HTML.
- PHP files use the `.php` extension.
- PHP code is processed by the PHP engine.
- PHP is commonly used for web application development.

## 2. PHP File Extension and Execution

PHP files must use the `.php` extension.

### Important Points

- PHP files must be saved using the `.php` extension.
- PHP files should be placed inside the XAMPP server root directory.
- The XAMPP server root directory is:

C:\xampp\htdocs

### My Practice File

C:\xampp\htdocs\test\week1practice\index.php

### Running the PHP Application

The PHP application can be accessed through a web browser using localhost.

http://localhost/test/week1practice/index.php

## 3. PHP File Structure

A PHP file can contain normal HTML code and PHP code.

### Example

<!DOCTYPE html>
<html>
<head>
    <title>PHP Practice</title>
</head>
<body>

<?php

echo "Welcome to PHP";

?>

</body>
</html>

PHP code is written between the PHP opening and closing tags.

## 4. PHP Tags

PHP code starts with:

<?php

and can end with:

?>

### Example

<?php

echo "Welcome to PHP";

?>

## 5. Echo Statement and Print Statement

The `echo` and `print` statements are used to display output in PHP.

### Echo

echo "Welcome to PHP";

Parentheses can also be used:

echo ("Welcome to PHP");

### Print

print "Welcome to PHP";

Parentheses can also be used:

print ("Welcome to PHP");

## 6. Multiple Arguments with Echo

The `echo` statement can display multiple arguments separated by commas.

### Example

echo "Majid", " is learning PHP";

### Another Example

echo "PHP ", "HTML ", "CSS";
